# Bilal Syahputra — Portfolio

Personal portfolio website. Plain HTML + CSS, no build step.

## Pages

- `index.html` — home: about, selected work, experience, contact
- `ndn.html` — Video Streaming over NDN (work in progress)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy on GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)`.
