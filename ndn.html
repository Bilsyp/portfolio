How it grew

From one stream to a system.

01

Stream our own video

The starting question: how do we play our own content over NDN instead of a ready-made demo?

02

Learn the codebase

Spent a long time understanding how the system and code work, working from the NDNts libraries.

03

Experiment, a lot

Built the app, configured the setup and tested in emulated networks and over the real internet — then repeated.

04

Next: multi-node

The current design is kept simple on purpose, so it can grow into a setup with many nodes.
